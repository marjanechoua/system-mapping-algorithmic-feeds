# System Mapping – Algorithmic Feeds & Construction of Reality

## Overview

A systems-thinking project exploring how algorithmic recommendation
systems can influence users' perception of reality and societal issues.

The project investigates the relationships between recommendation
algorithms, user behavior, content exposure, and societal discourse.

## Research Question

How do recommendation systems influence users' perception of reality
and societal issues?

## Methods

- Systems Thinking
- System Mapping
- Causal Relationships
- Feedback Loops
- Leverage Points
- Human-Centered Design

## My Contribution

- Developed and structured the system map
- Identified relevant variables and causal relationships
- Analyzed feedback loops within the system
- Identified key insights and potential leverage points
- Developed interview questions for further validation

## Tools

- Miro

## Project Outcome

The system map visualizes the main variables and relationships
identified during the analysis and highlights feedback loops that
may reinforce users' exposure to certain types of content.

## Project Outcome

The project resulted in a system map exploring how algorithmic
recommendation systems can influence users' perception of reality
and societal issues.

This project helped me understand how complex digital systems can
